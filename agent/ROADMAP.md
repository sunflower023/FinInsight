# Roadmap

> 本路线图只描述后续工作。完成度以 `PROJECT_CONTEXT.md` 和
> `DEVELOPMENT_CONTEXT.md` 的源码核对结果为准。

## 阶段 0：工具链和基础可信性

目标：让 Qt 主工程可以编译，并让异步网络和数据适配具有可重复验证入口。

- [ ] 修复 CMakePresets 的本机 Qt/Ninja 路径问题，记录 Qt、MSVC 和 CMake 版本。
- [ ] 编译 Qt 主工程，修复 `KLineData` 复权字段和历史价格桥接带来的兼容问题。
- [ ] 为 HttpClient 补充异步响应、超时、取消和 context 销毁测试。
- [ ] 为 QuoteAdapters/Aggregator 接入现有离线 fixture，覆盖成功、全失败、总超时、取消和迟到回调。
- [ ] 明确缓存优先、网络失败和数据质量降级策略。

## 阶段 1：完成可用的模拟交易闭环

目标：用户能在 Qt 界面执行一次可验证的模拟交易，结果来自唯一账本。

- [ ] 让 `PortfolioPanel` 使用 `simulation::Ledger`，移除面板内重复的临时现金/持仓计算。
- [ ] 让当前标的和最新 `QuoteData` 注入买卖面板，完成买入、卖出、余额不足、持仓不足和非法输入提示。
- [ ] 用账本估值结果刷新现金、持仓市值、总权益、已实现/未实现盈亏和收益率。
- [ ] 展示真实账本交易记录，明确手续费、成交价格、时间戳和模拟性质。
- [ ] 增加历史实验输入界面：标的、起止日期、初始资金、手续费和普通/复权价格口径。
- [ ] 将 `HistoricalPriceAdapter` 接入 K 线回调，把历史价格序列传入 `InvestmentExperiment` 并展示收益率、最大回撤和错误原因。

## 阶段 2：实验可复现和风险指标

目标：实验结果可保存、复算、比较，并具有基本风险解释。

- [ ] 设计 SQLite migration，保存实验配置、交易记录、价格口径、数据源、日期范围和结果快照。
- [ ] 实现基准序列与标的序列的交易日对齐、基准收益和超额收益。
- [ ] 增加波动率、夏普比率、集中度等指标，明确年化、无风险利率和缺失数据口径。
- [ ] 支持组合层净值曲线、仓位限制、定投和再平衡前，先固定单标的实验契约。
- [ ] 将 DSL 绑定历史 K 线，形成时间序列求值和最小回测链路。

## 阶段 3：行情实时化

目标：只有在数据源、协议和合规边界确认后，再增加实时流。

- [ ] 先确认目标市场、可用 WebSocket 数据源、鉴权方式、消息格式和许可边界。
- [ ] 在 Qt Network 中增加独立 WebSocket 客户端：连接状态、订阅、心跳、超时、重连、退避和主动取消。
- [ ] 将规范化实时报价转换成 `QuoteData`，通过 DataHub 发布；断线时保留最后值并显示状态。
- [ ] 不让 WebSocket 绕过 Aggregator/缓存质量规则，也不在 UI 线程解析大型消息。

## 阶段 4：行为复盘 Agent

目标：基于已保存的模拟证据做教育性复盘，不提供荐股或自动下单。

- [ ] 先实现确定性的行为指标和规则：频繁交易、追涨杀跌、集中度、回撤忽视。
- [ ] 定义证据包格式：交易记录、持仓变化、收益/回撤/波动指标和对应时间段。
- [ ] 再选择本地模型或远程 LLM 接口，增加超时、失败、脱敏和成本限制。
- [ ] Agent 输出必须区分事实、推断和教育性建议，每条结论附证据引用。
- [ ] 增加风险提示、模拟免责声明、禁止确定性收益承诺、荐股和自动下单的产品约束。
- [ ] 最后增加 Agent 面板和离线回放测试，不把 Agent 调用放进交易执行路径。

## 阶段 5：工程化

- [ ] Windows CI：Qt 构建、核心 CTest、格式检查和静态搜索。
- [ ] 扩充离线 fixture，网络测试不依赖 Yahoo/EastMoney 在线服务。
- [ ] 为 JSON 解析、指标计算、回撤和实验输入增加基准测试与故障注入。
- [ ] 将 UI、数据源、模拟核心、实验指标和 Agent 证据组装拆成可独立测试的 target。
