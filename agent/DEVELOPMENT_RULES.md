# Development Rules

## 修改前

- 用 `rg` 找到接口的所有调用方。
- 判断改动属于 UI、数据管道、传输、存储还是纯算法。
- 先确认是否已有用户未提交修改，不覆盖无关变更。

## 修改中

- 公共接口优先返回明确的错误状态，不用空对象静默吞错。
- 外部 JSON 必须检查字段存在、数组长度和类型。
- 算法函数必须处理空输入、短输入、非法周期。
- 不在 QWidget 中直接拼接 SQL 或发起长时间网络请求。
- 新增 topic、表字段或 DSL 语法时同步更新文档。

## 修改后

- 有构建环境就执行 `cmake --build --preset win-dev`。
- 至少做一次 `rg` 静态检查，确认新接口确实被调用。
- 为纯算法和 Parser 增加最小测试；无法运行时说明阻塞原因。
- 更新 `docs/QUICKSTART.md` 或 `agent/PROJECT_CONTEXT.md` 中受影响的状态。
